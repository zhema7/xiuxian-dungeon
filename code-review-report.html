二、高优先级问题（3个）

BUG-01 区域秘境 lastSceneData 存档丢失

文件：src/scenes/DungeonScene.ts 第338行

严重程度：高

问题描述：lastSceneData 只保存了 floor、diff、mode，没有保存 regionOverrideId。在区域秘境（楼兰、冰原、破碎仙宫等）中保存退出后，"继续游戏"会进入普通地下城（青冥山脉）而非玩家之前所在的区域秘境。

影响：玩家在区域秘境中下线后重进，会被传送到错误的区域，可能导致进度丢失或体验困惑。

修复建议：在保存 lastSceneData 时加入 regionOverrideId、name 等区域信息，TitleScene 恢复场景时传入完整数据。

BUG-02 已发现秘境入口场景重启后消失

文件：src/scenes/WorldScene.ts 第120行、第3122-3128行

严重程度：高

问题描述：discoveredRealmDefs 是场景成员变量，场景切换/重启后被清空。虽然 discoverRealm() 将秘境 ID 存入 state.discoveredRealms，但 create() 中从未从 state 恢复并渲染已发现的秘境入口。玩家重新进入大地图后，之前发现的秘境入口全部"消失"。

影响：玩家探索发现的秘境入口在离开大地图后就没了，需要重新发现，严重影响探索体验。

修复建议：在 create() 中遍历 state.discoveredRealms，根据保存的秘境数据重新生成秘境定义并调用 renderSecretRealmEntrance() 渲染入口。需确保秘境入口坐标也持久化到 state。

BUG-03 死亡时 lastScene 未更新

文件：src/scenes/DungeonScene.ts 第3999行附近

严重程度：高

问题描述：玩家在地下城中死亡后，存档时 lastScene 仍为 'Dungeon'。若此时关闭游戏，下次继续游戏会以 0 HP 重新进入地下城，可能导致死亡循环。

影响：极端情况下玩家可能无法继续游戏（每次进入都是0血立即死亡）。

修复建议：死亡处理流程中，将 lastScene 重置为 Town 或 City 场景，并恢复一定生命值，确保玩家"复活"在安全区域。

三、中优先级问题（13个）

3.1 战斗与掉落系统

编号问题描述程度修复建议
M-01 伤害计算使用 Math.random dealDamage 中暴击判断使用 Math.random 而非 this.rng()，破坏了RNG确定性和可重现性。 中 统一使用 this.rng()
M-02 玩家受伤使用 Math.random damagePlayer 中伤害浮动同样使用了非确定性随机源。 中 统一使用 this.rng()
M-03 gainExp 无等级上限 经验升级 while 循环没有最大等级限制，一次性获得巨量经验时可能导致性能问题或数值溢出。 中 增加最大等级上限 MAX_LEVEL 保护

3.2 场景系统

编号问题描述程度修复建议
M-04 sectEventTimer 未持久化 宗门随机事件计时器是场景成员变量，离开宗门场景后重置为0。玩家频繁进出宗门会导致随机事件永远无法触发。 中 保存到 state.sect.sectEventTimer
M-05 recruitCandidate 未持久化 招募候补弟子是场景成员变量，离开宗门场景后丢失。特别是"游方修士到访"事件生成的候补弟子，离开后再回来就消失了。 中 序列化保存到 state.sect.recruitCandidate
M-06 宝物发现事件无兜底 当宗门没有 idle 或 cultivating 状态的弟子时，宝物发现事件被触发但没有任何提示或效果，玩家完全无感知，事件"空转"。 中 添加 else 分支给出提示，或从全体弟子中选取
M-07 instructorBonus 赋值错误 使用 = 赋值而非累加，如果有多名 instructor 或大长老，只有最后一个的加成生效，其余被覆盖。 中 若设计为叠加则改用 +=；若单个生效则 break
M-08 传送菜单目标描述错误 openTeleportMenu 中列出传送目标时，错误地使用了当前传送阵描述而非目标点描述，导致所有目标显示同一段文字。 中 将 p.description 改为 t.description

3.3 UI与音频系统

编号问题描述程度修复建议
M-09 配装方案切换自动覆盖 切换方案时，如果有活跃方案，会先将当前配置自动保存到当前活跃方案，再加载目标方案。可能导致用户在不知情的情况下覆盖之前保存的方案。 中 增加确认提示，或在 toast 中明确提示"已保存至方案X"
M-10 基础UI音效无合成回退 AUDIO_KEYS 中定义了14个基础音效，但 synthMap 中只有 sfx_portal 有对应定义。音频文件加载失败时大部分UI音效会完全静默。 中 为 sfx_click、sfx_open、sfx_equip 等高频音效添加合成回退
M-11 SectWarScene 无专属BGM 宗门战争场景的 create() 中未调用 playBgm()，会继续播放进入前的BGM（如宗门BGM），与战斗氛围不匹配。 中 复用 BGM_ARENA 或新增战斗BGM
M-12 activeRelationQuests 类型 类型为 unknown[]，缺乏类型安全，存储和读取时不校验内部结构。 中 定义 RelationQuest 接口，做数据规范化
M-13 innerDemons 类型为 any[] 使用 any 完全失去类型保护，可能导致运行时错误。 中 定义 InnerDemon 接口替换 any

四、低优先级问题（部分列举）

数据与代码质量

  • presets 注释与实际数量不一致：注释写"×5"，实际 PRESET_COUNT = 6
  • 灵窍成功率缺少下界保护：只有 Math.min(0.99, ...) 上限，无 Math.max 下限
  • masterGain 全局音量污染：多音效同时播放时后播放的会改变先播放的音量
  • sfx 函数 volume 参数无边界检查：未 clamp 到 [0, 1]
  • elderBonus 变量声明但未使用：SectScene 中死代码
  • productionTimer 精度累积问题：重置为0会丢失超出的时间精度，长期有微小偏差
  • 秘境发现概率使用 Math.random：与 this.rng 不一致
  • BGM_SOUTH_ALT 导入但未使用：WorldScene 中引入了常量但从未引用
  • 跨域切换通过 scene.restart()：性能开销大，可优化为增量更新
  • BGM 切换时音频不存在静默无提示：建议开发模式增加 warn 日志
  • 非无尽模式精英率无上限：理论上精英率可能超过100%
  • Boss 双重装备掉落：死亡掉落与战利品可能重复
  • 升级回血不随升级次数叠加：每次升级只加一次上限提升的血量
