## 专利 XML 上传报错与政策（第八次 · 重要）

- 用户反馈：专利业务办理系统上传 XML 压缩包提示"XML 解析/标签校验失败"（在说明书/权利要求书正文环节）。
- **关键政策（2026-01-01 起生效）**：国知局全面实施 XML 强制提交，不再接受 PDF/DOC 等非 XML 格式。XML 必须符合**国知局自有数据标准 Schema（DTD 校验）**，且字符集要求 **GB18030**、新申请段号/权项号由系统自动生成。
- 根因：之前手写的 `发明1-说明书.xml`（WIPO ST.36 命名空间+自定义元素名）不符合国知局 Schema，必然校验失败。**手写 XML 不可行，必须用官方「WORD转XML编辑器」（专利业务办理系统"工具下载"栏目）从规范 Word 转换。**
- 环境限制：python-docx / reportlab / pandoc / libreoffice 均不可用（pip 装 python-docx 因 lxml 4MB 下载被网络卡住失败；无 PDF/文档转换工具）。PIL 可用但不渲染 SVG。
- 解决方案落地：用纯 Python `zipfile` 手写最小合法 .docx（设置宋体小四/A4/页边距），生成三份 `docs/专利材料/发明1-{说明书,权利要求书,说明书摘要}.docx`，供用户用官方工具转 XML。已验证 zip 完整、含 document.xml、中文正常。
- 附操作指引 `docs/专利材料/00-提交操作指引.md`（政策解读+工具下载+Word版式+转换上传步骤+常见校验错误规避）。
- 附图：保留 SVG 矢量源，指引用户侧转 JPG/TIF(72-300DPI) 随案卷包上传。
- 长期结论：本项目专利/软著类交付，凡涉及国知局系统上传，一律走"规范 docx → 官方 WORD转XML 编辑器 → XML"路径，不再手写裸 XML。
