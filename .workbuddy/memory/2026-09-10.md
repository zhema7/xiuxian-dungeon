# TapTap H5 线上崩溃 + 英文文案泄漏修复（2026-09-10 20:00）

## 用户反馈（3 张手机截图）
- 图1：进入大地图即黑屏，`TypeError: Cannot read properties of undefined (reading 'sys')` @ `phaer-0RJB29YE.js:1329`，调用链 `refreshMountSprite → setTexture`
- 图2：`Promise: Cannot read properties of null (reading 'drawImage')`，栈 `updateUVs → setCutPosition → setSize → updateText`（场景切换后才抛，属未捕获 Promise）
- 图3：见闻录文案 `ai_sect_4 击败了 ai_sect_0, 获得wood×63`

## 根因（用本地 dist 反查 minified 行列确认）
- Phaser `DisplayList.shutdown()` 会逐个 `destroy(true)` 场景对象；`GameObject.destroy()` 把 `this.scene` 置空、`Frame.destroy()` 把 `this.data` 置空。
  → **跨场景残留引用再调用即崩**：`setTexture` 读 `this.scene.sys`、`Text.updateText` 读 `frame.data.drawImage`。
- 图1 = `WorldScene.mountSprite` 只按需创建，没进 create 的「清理上一轮残留引用」块（同块 npcSprites/npcLabels/… 都清了，独漏它）→ 二次进入大地图且已召唤坐骑必崩。
- 图2 = 4 个场景的 `tryCompleteQuest(...).then(() => questHud.setText(...))`：任务完成对话框是异步等玩家点击，期间玩家切场景 → 回调时 questHud 已销毁。

## 修复
- `WorldScene`：清理块新增 `this.mountSprite = null`；`refreshMountSprite()` 增加 `if (this.mountSprite && !this.mountSprite.scene) this.mountSprite = null` 兜底。
- `WorldScene/CityScene/SectScene`：回调首行 `if (!questHud.scene) return`；`TownScene` 改为 `if (this.questHudText?.scene)`。
- 新增 `src/labels.ts`：`resourceLabel / materialLabel / buildingLabel / sectLabel`（'player'→你方），均带中文兜底词。
  修复泄漏点：sect-war（resourceType / winner / loser / annihilatedId / formAlliance / annex）、diplomacy（建筑 id→名）、sect-building-v2、annual-events、deep-event-chain、story-quests、relation-quests、realm-ecology（goods.item 与 HP-50）、karma-v2（HP→气血）、tribulation-v2（HP→气血）、DungeonScene（v4KitId 兜底）、ui.ts（功法名/职业名兜底）。
  ⚠️ `resolveWar` 里 attacker/defender 名必须在「灭门移除 aiSects」之前取好，否则会退化成「未知宗门」。
