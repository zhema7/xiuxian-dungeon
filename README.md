# 修仙与地下城

竖屏单手操作的像素修仙 Roguelike：探索随机秘境、收集功法套装、突破境界、建立宗门。每一次下洞，都是一场全新的机缘。

**在线试玩**：https://zhema7.itch.io/xiuxian-dungeon

## 特性

- **五脉仙途** —— 剑修 / 仙子 / 法修 / 道修 / 合欢，各成本命道统
- **肉鸽秘境** —— 随机地图 + 随机词条装备，每层都是新的 Build
- **功法自由配** —— 上万种功法装配组合，万剑归宗或符箓通玄由你定义
- **境界突破** —— 炼气至飞升，渡劫失败会怎样？试试就知道
- **洞府经营** —— 招收弟子、炼器炼丹、布下你的护山大阵
- **大世界** —— 苍玄大陆五域探索、AI 宗门博弈、NPC 恩怨情仇
- **HD-2D 画面** —— 3D 场景 + 像素角色，致敬 Octopath Traveler

## 技术栈

TypeScript + Phaser 3 + Vite，单代码库输出 H5 与移动端。

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建产物输出至 dist/
```
