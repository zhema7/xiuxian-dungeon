## 四、设计说明

- **统一主视觉**：全部物料沿用游戏内标题界面美术（青冥山夜空、明月、云海、仙鹤）的配色与语言，主色为深靛蓝（`#070b22` ~ `#3e5492`）、月白（`#fbf3d3`）、暖金（`#f8cd63` ~ `#b97708`）。
- **标题字**：使用行楷字体 + 金色竖向渐变 + 深色描边 + 双层金色外发光，与游戏内标题界面一致，保证品牌统一。
- **图标**：直接取自游戏主视觉中「明月 + 主峰 + 云海 + 仙鹤」区域，叠加暖金辉光与双层金色内框，画面为明亮的青蓝夜空。
- **封面图**：两张封面**画面内均只保留游戏名**，不带副标题等任何其他文字；横版封面改用按 460×215 比例专门绘制的夜景主视觉（不再使用实机截图裁切），标题居中且四周留足净空，避免被遮挡或裁切；竖版封面为主视觉原图压暗后居中叠标题字。
- **标题不贴边保障**：生成脚本在渲染前会用 `getBoundingClientRect()` 实测各素材标题字宽，若超出「卡片宽 − 2×安全边距」则自动下调字号，并打印实测净空；本批实测结果：LOGO 净空 13px / 宣传图 16:9 净空 339px / 宣传图 1:1 净空 137px / 横版封面净空 67px / 竖版封面净空 49px，全部通过。
- **宣传图**：按官方要求**不使用游戏截图**，为纯绘制的夜景主视觉，画面内**除游戏名外无任何其他文字**、**不含图标元素**。

## 五、复现 / 重新生成

物料由 `tools/_promo_board.py` 渲染 `promo/_build/board.html` 生成，全部为精确像素尺寸、1:1 输出（无缩放损失）：

```powershell
cd "c:\kimi\修仙与地下城"
python tools\_promo_board.py
```

- 修改文案 / 尺寸 / 构图 → 编辑 `promo/_build/board.html` 对应卡片后重跑脚本。
- 重新采集实机截图 → `python tools\_promo_v10.py all`（需先 `npm run build` 生成 `dist/`），新图落在 `promo/_v10/`，再手动挑选覆盖到 `02-screenshots/`。
- 依赖：`playwright`（Chromium）、`Pillow`。脚本内置本地 http 服务（端口 8900），仅用于渲染时读取项目内贴图。

1. **旧文案声明**：`game-intro/game-intro.txt` 中写有「仅供交流测试，非商业用途」，与 TapTap 正式上架定位冲突，上架前请确认是否删改。
2. **截图内等级与境界**：为确保画面饱满，截图使用了「Lv.45 / 炼气」的存档，HUD 会显示该数值；如需更贴合实际体验，可重新采集更早期进度的画面。
3. **截图分辨率**：官方允许竖版截图 ≥720×1280。本次为 720×1280（游戏逻辑分辨率 360×640 的 2 倍整数倍），若后台提示偏小，可按 3 倍导出为 1080×1920。
4. **文字合规**：宣传图严格只保留游戏名；封面图与 Logo 中的副标题文字属非「宣传图」素材，规范未限制。
5. **H5 包体**：本次素材对应 `release/修仙与地下城-taptap-20261015-v1.0.zip`（v1.0.0）。
