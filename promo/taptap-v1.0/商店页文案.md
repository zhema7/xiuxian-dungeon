## 二、游戏简介（商店页主文案）

```
《修仙与地下城》是一款竖屏 2D 像素的玄幻修仙 Roguelike RPG。你从一介炼气期散修起步，闯程序化生成的地下城，刷怪拾宝、突破境界，构筑属于自己的战斗流派。

—— 轮回不止的修仙循环 ——
选道统 → 闯秘境 → 刷装备 → 配功法 → 破境界 → 立宗门 → 挑战更深层。死了有惩罚，但不归零；局内搭 Build，局外养角色。

—— 五大职业，五种打法 ——
剑修连击攒「剑意」，仙子远程轰炸，法修符箓绵长，道修厚血重防，合欢会心致命。职业不锁死，遇见稀有功法就能跨系混搭——剑修学魔功、仙子玩符箓，全看掉落与搭配。

—— 七重境界，雷劫加身 ——
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 大乘。
突破不只看等级和材料，还要硬扛天劫：一道道雷劈下来，走位躲不好，就是灰飞烟灭。

—— 可玩的东西很多 ——
· 九大场景：洞府、天枢城、大地图、宗门、地下城、天劫……从家里炼丹锻造，到城里坊市擂台，再到五域赶路探索。
· 装备掉落：散件追数值，套装 2/4/6 件改机制，还有稀有的神通套件。
· 功法与天赋：招式 / 心法 / 神通三系，天赋三分支自由加点，配装方案随存随切。
· 宗门经营：建十余类建筑，收弟子、养灵兽、布阵法；宗门战争是一整套塔防玩法。
· 会生活的 NPC：程序化生成，有日程、有亲疏、有好恶，能交友，也能结仇。
· 大地图探索：五域各有独特地形与区域名，秘境名称随区域变化，赶路会加速时间流逝——速度属性终于有了意义。
· 因果与心魔：做好事做坏事都有后果，影响事件走向与 NPC 对你的态度。
· 世界会变：AI 宗门会兴衰，年度事件会发生，你不在的时候世界也在走。

—— 竖屏单手，打开就玩 ——
专为竖屏设计：左手摇杆走位，右手点按攻击 / 神通 / 丹药，单手通勤也能刷一趟秘境。也支持 PC 端 WASD + 鼠标操作。浏览器打开即玩，存档保存在本地，四个存档槽随时切换。

修仙这条路，一步一个脚印。
```

## 三、开发者的话（选填）

```
这是一款由一个人开发的独立游戏。

我很喜欢两类东西：一类是《暗黑破坏神》那种"掉落改变流派"的刷宝手感，一类是修仙小说里"境界一层层熬上去"的成长感。市面上两者兼得的不多，于是干脆自己做了一款。

《修仙与地下城》想做的其实很简单：让你在通勤路上掏出手机，单手就能刷一趟秘境，掉一件装备，改一次功法搭配，然后看一眼自己的境界还差多少能突破。不需要开局教程，也不需要背一大段设定。

开发到现在，游戏里已经跑着六十多个系统模块：大地图、宗门建设、程序化 NPC、阵法塔防、天劫、灵兽、因果心魔……很多东西是我自己写着写着觉得"这个有意思"就加进去的。也正因为如此，它还有很多可以打磨的地方——数值平衡、新手引导、性能优化，都还在继续。

v1.0 是第一个我敢拿出来叫"正式版"的版本：核心循环跑通了，bug 也清了一轮（比如之前随机秘境的传送门会把人误传到常驻秘境，这个已经修好）。

如果你玩到了什么奇怪的东西，或者觉得某个流派特别有意思，欢迎在评论区告诉我。修仙不易，但一起熬境界还挺好玩的。

—— 哲码游戏
```

## 四、更新日志（必填）

```
【v1.0 正式版】

本次为 v1.0 正式版本，主要围绕"把核心循环打磨到可以长期玩"做了一轮修复与调优。

■ 修复
· 修复随机秘境传送门误传至常驻秘境的问题：进入随机秘境下一层时未携带秘境标识，导致层数推进后跳回常驻秘境；现已补全标识传递。
· 修复随机秘境通关后缺少进度记录的问题：通关后现在会正确更新秘境探索进度、写入层数标记，并清理临时状态，避免下次进入残留数据。

■ 体验调整
· 提升战斗挑战性：上调各难度模式下敌人的反制率与反制下限，敌人的打断与反打更积极，站桩输出不再安全。
· 整体数值与节奏随之上调对齐，中后期秘境难度曲线更陡，Build 搭配的重要性进一步放大。

■ 版本
· 版本号升级为 v1.0.0，作为 TapTap 正式版发布。
```
