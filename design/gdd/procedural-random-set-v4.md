## 1. 八原语行为契约

> 每个 Kit 的普攻与神通各取一个原语。原语行为在普攻侧与神通侧**各自独立定义**（同名原语在两侧表现可不同）。下表是行为规格，非数值；数值见 §4。

| 原语 | 普攻侧（normal attack）行为 | 神通侧（art）行为 |
|---|---|---|
| **往返 roundtrip** | 投射物向前飞行后折返，去程与返程各命中一次；单目标最多吃两段 | 释放一柄可折返重器，往返路径上敌人各受一次重击 |
| **折射 refract** | 投射物命中首目标后折射至最多 N 个次目标（链式） | 释放折射光阵，在场上多点之间弹射 |
| **标记 mark** | 普攻对命中目标施加「标记」；被标记目标受创额外 +X% | 神通对范围内所有目标批量施加标记，并引爆已有标记 |
| **定点 fixedpoint** | 在瞄准点/脚下生成定点打击（地面突刺/落石） | 在指定位置部署一次定点爆发 |
| **雷网 thundernet** | 普攻即张小范围雷网，网内多目标持续受击 | 张开大范围雷网，网内全部目标周期性受雷击 |
| **雷桩 thunderstake** | 普攻落一根雷桩（持久实体），周期脉冲周围 | 落数根雷桩，桩间连电形成封锁区 |
| **蓄力 charge** | 普攻可蓄力：按住蓄能，松开释放强化段（蓄满倍率更高） | 神通蓄力后释放一道贯穿波，蓄时越长越强 |
| **回旋 boomerang** | 普攻为环形/回旋挥砍，周身全向命中 | 释放回旋法器，绕角色旋转多圈持续伤害 |

**命名约定**：原语标识采用上表英文短名（`roundtrip`/`refract`/`mark`/`fixedpoint`/`thundernet`/`thunderstake`/`charge`/`boomerang`）。这是 v4 内部原语枚举，**不并入** `AttackMode` / `ArtMode` 联合类型（见工程 ADR §3）。

## 4. 数值与平衡框架（lean，待模拟器）

> v4 数值在平衡模拟器落地前**不可宣称平衡 PASS**。下列为口径，非最终数值。

- 每 Kit 4 件套提供：独立普攻原语（替换默认攻击）、独立神通（替换神通）、独立命中特效。
- 数值预算沿用既有口径：同层 DPS 比 ≤ 3×（批 2 门）、清层窗口 60–180s、任一 Kit 胜率 40%~80%、同层 Kit 间通关时间差异 ≤ 25%。
- 雷网/雷桩为持久实体，须设帧上限/数量上限（防爆栈/死循环，见 QA）。
- 蓄力原语须定义蓄力段数（建议 3 段：未蓄/半蓄/满蓄）、蓄满倍率上限（≤ 满血同 Build 2.2×，沿用魔修阈值口径）、蓄力期间移速惩罚。
- v4 不可与旧 v2/v3/legacy 套混穿触发对方机制（混穿来源独立性，批 3 门）。
