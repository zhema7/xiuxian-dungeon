# 模块化套装攻击特效提示词包（30 张以内）

> 目标：最多新增 30 张基础贴图，通过代码组合现有攻击素材，实现 20～30 种随机套装招式/神通变体。
>
> 核心原则：**贴图负责核心形状，代码负责数量、方向、旋转、缩放、染色、延迟、环绕、追踪、穿透、链路和范围。**

## 1. 统一图片规格

所有新增图片统一：

```text
48×48 像素风，透明背景，RGBA PNG，单个独立特效，
主体居中，边缘清晰，无文字，无角色，无场景，
无黑色方框，无白色背景，不要多个效果拼在一张图里，
适合 Phaser 序列帧动画、Sprite 和 tint 染色。
```

通用负面提示词：

```text
不要文字，不要数字，不要 UI，不要角色，不要场景，
不要地面背景，不要黑色背景，不要白色背景，不要方形底色，
不要多个特效，不要六宫格，不要拼图，不要写实风，
不要 3D 渲染，不要照片，不要固定视角偏斜，不要裁切主体，
透明背景，单个 centered sprite。
```

方向规范：

- 飞剑、剑影、飞行弹道：朝右绘制，代码使用 `setRotation(angle)`。
- 爆发、光环、法阵、领域：圆心居中，代码不旋转。
- 不在图片中预烘焙旋转角度。
- 一次性爆发建议 4～8 帧；循环飞行/持续区域建议 6～8 帧。

## 4. 20 种攻击效果映射

### 飞剑类

1. **飞剑分裂**：`sword_proj + mod_hit + mod_blade × 2~3`。命中后播放小型闪光，复制剑影按扇形发射。
2. **飞剑追踪**：`sword_proj + mod_blade`。代码持续修正飞剑角度。
3. **飞剑穿透**：`sword_proj + mod_hit`。命中不销毁，播放命中反馈后继续飞行，伤害递减。
4. **飞剑回旋**：`sword_proj + mod_blade + mod_hit`。飞出后沿弧线返回，回程命中反馈。
5. **飞剑环绕**：`mod_blade × N + mod_charge`。剑影围绕玩家，达到数量后发射。
6. **扇形剑气**：`slash_anim × 3~5`。复制现有月牙刀光，改变角度和延迟。

### 弹道类

7. **火弹爆炸**：`bolt_fly + mod_burst`，命中后橙红 tint。
8. **冰弹爆炸**：`bolt_fly + mod_burst + mod_field`，冰蓝 tint，结束后留下减速区。
9. **弹道分叉**：`bolt_fly + mod_charge + bolt_fly × 2~3`，蓄力后复制子弹并改变角度。
10. **弹道穿透**：`bolt_fly + mod_hit`，命中后继续飞行。
11. **弹道追踪**：`bolt_fly / proj_fly`，只改角度和速度。
12. **弹道环绕**：`bolt_fly × N`，通过极坐标围绕角色或目标旋转。

### 法术类

13. **大范围法术**：`mod_rune + fx_ring + mod_burst`，符文、扩散环、爆发三段式。
14. **延迟爆炸**：`mod_rune + mod_charge + mod_burst`，留下标记后延迟引爆。
15. **多点落雷**：`mod_rune + mod_hit`，落点和雷柱连接线用 Graphics。
16. **持续法术领域**：`mod_field + mod_rune`，循环区域，周期造成伤害/减速。
17. **法术蓄力**：`mod_charge + mod_rune`，通过缩放、旋转、透明度表达蓄力。

### 阵法类

18. **阵法地雷**：`mod_rune + mod_charge + mod_burst`，阵眼放置、预警、爆炸。
19. **连锁阵法**：`mod_rune + mod_hit + mod_burst`，阵眼依次激活，连接线用 Graphics。
20. **阵法禁区**：`mod_rune + mod_field`，符文表示边界，区域表示持续效果。

额外可组合：死亡灵爆、雷链传导、伤害回响、反弹弹道、爆炸分裂、火焰地面、冰霜减速区、毒雾领域、护体光环、低血量爆发。

## 5. 随机套装规则

套装效果字段：

```text
元素主题：火 / 冰 / 雷 / 剑 / 阵 / 魂 / 毒
攻击载体：飞剑 / 弹道 / 神通 / 阵法 / 近战
核心变体：分裂 / 追踪 / 爆炸 / 连锁 / 延迟 / 领域 / 环绕 / 回响
触发条件：命中 / 暴击 / 击杀 / 连击 / 阵法结束 / 低生命
数值参数：伤害倍率 / 范围 / 持续时间 / 冷却 / 叠层数 / 数量
视觉标签：主色 / 辅色 / 形状 / 是否序列帧
```

建议套装层级：

- 2 件套：附加触发，如命中小爆炸、飞剑产生剑影、雷击传导一次。
- 4 件套：改变攻击形态，如分裂、追踪、延迟爆炸、地雷化。
- 6 件套：形成完整战斗循环，如护体剑轮、持续领域、击杀灵爆、伤害回响。

互斥或高风险组合：

```text
无限穿透 + 无限分裂
追踪 + 环绕
超大范围 + 高频触发
延迟爆炸 + 极短冷却
持续领域 + 无限叠加
高攻速 + 高倍率回响
```

每个套装最多包含：

```text
1 个攻击载体 + 1 个核心变体 + 1 个触发条件 + 1 个数值修饰 + 1 个视觉元素
```
