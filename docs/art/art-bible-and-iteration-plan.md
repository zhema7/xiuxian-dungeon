## 0. TL;DR（给主理人 30 秒版）

- 视觉基线**已经立住了**：`title_bg.png` 与 `cave_bg.png` 是大插画金标准，`fairy_spritesheet.png` 是角色帧表金标准，整个项目的"夜色山水 + 主题色分区"风格可以以此为锚。
- 本次美术迭代的核心动作是**"以仙子表为标尺、收口 C 档、补齐三职业"**：(1) 把偏柔/偏离规范的特效（slash、sword_proj）重做；(2) 剑修帧表返工至仙子品质；(3) 补齐丹修/阵法师/魔修三个职业帧表。
- 关键风险（详见第 6 节）：**剑修表返工需工程脚本协作**、**三职业批量产出的一致性风险**（建议拆批 + 仙子表为验收门槛）。（原风险 1「title_bg 缺口与现状不符」已于 2026-08-22 用户确认定稿、缺口关闭。）
- 可访问性采用 lean 级：品质色**双编码**（色 + 边框 + 光柱密度 + 形状），不依赖单一颜色通道。

## 2. 美术圣经（视觉身份）v0.1

### 2.1 一句话原则

> **"夜色山水 + 主题色分区"**：以 `cave_bg` / `title_bg` 确立的「深青蓝紫夜色 + 暖光点缀」为基线，每个地区以**主题色轮换**；强调**描边一致、剪影可读、品质与职业靠"形与色"双重区分**。

### 2.3 像素规范升级（在 `docs/04` 第一节基础上新增/收紧）

保留：`docs/04` 的全部硬性要求（16 倍数尺寸、2D 像素风、top-down 3/4 视角、PNG RGBA 透明底、1px 深色描边、禁抗锯齿、禁渐变光晕、禁文字水印）。

新增/收紧：

- **调色板规模（每图独立限色）**：
  - 角色帧表：单图 ≤ 24 色
  - 16×16 怪物、8×8 道具：单图 ≤ 16 色
  - 粒子特效：单图 ≤ 12 色
  - 理由：限制 AI 涂色自由度，保证系列素材统一。
- **描边统一**：所有 ≥ 16×16 实体用 `#0A0E1A` 1px 描边；8×8 道具可省描边但需深色边缘对比。**反例**：`slash.png` 当前软发光无描边，违反规范。
- **光影处理**：
  - 禁止渐变光晕
  - 高光用**单像素高光点**（1~2 px）
  - 阴影用**单一深色色阶**（比主色深 2~3 阶）
  - 不使用多级阴影
  - 参考 `cave_bg` 灯笼的处理（亮黄 + 一圈暖橙，不糊不渐变）
- **抗锯齿禁令强化**：C 档素材（`slash` / `sword_proj` / 部分 `deco`）当前是软边/带光晕 → 需重生成或手工像素修。
- **剪影可读性测试**（入库前必过）：在 `#0A0E1A` 黑底上把图缩到 16×16 仍能辨认职业/怪物/物品 → 通过方可入库。
- **尺寸基准**（与 `docs/02` 第三/七节对齐）：
  - 设计分辨率 **360×640**（pixelArt:true、最近邻缩放）
  - tile 16×16 整数倍
  - 角色帧表 64×64/帧（详见 `docs/04` 第四节）
  - 单图透明、单 bundle ≤ 300 MB（`docs/04` 上限）、首包目标 < 5 MB（`docs/02` 目标）

### 2.4 角色与怪物的视觉语言统一原则

#### 2.4.1 职业识别：形 + 色双编码

| 职业 | 武器 | 剪影特征 | 主色 |
|---|---|---|---|
| 剑修 | 长剑 | 立领、青白长袍、剑随身侧 | 霜白 + 剑青 |
| 仙子 | 法杖/绫带 | 广袖、绫带飘动、头饰 | 淡紫 + 月白 |
| 丹修 | 丹炉 + 药杵 | 圆炉背身、药杵短握、围裙感 | 丹红 + 药金 |
| 阵法师 | 阵盘 + 符笔 | 阵盘悬腕、符笔夹指、宽袖 | 阵蓝 + 符黄 |
| 魔修 | 魔刃/骨器 | 兜帽遮面、长刃斜背、足下紫雾 | 魔紫 + 血黑 |

> 形是主识别通道，色是辅助。**任何两个职业不能仅靠色相区分**。

#### 2.4.2 怪物按生态区分

- **妖虫系**（slime / bat / spitter / moth）：小型高对比，单眼或复眼，整体填满 16×16。
- **鬼魅系**（wraith）：半透明 + 飘浮，无腿，紫色雾气边缘。
- **兽形系**（tortoise / golem / eagle）：四足 + 重甲/羽翼，体型饱满。
- **植物系**（flower）：静态根茎 + 花冠攻击，对称构图。
- **人形 Boss**：32×32（游戏内放大 1.9× 或 1.55×），气场大于体型，**底部 1px 深色接地阴影**（浮空型除外）。
- **浮空型**（wraith、部分 Boss 阶段）：无接地阴影，底部留 1~2 px 透明。

#### 2.4.3 体型比例

- 人类角色（64×64 帧）：头身比约 **1:3**（参考仙子表）。
- 怪物（16×16）：整体填满，**不画独立接地阴影**。
- Boss（32×32）：头身比约 **1:4**，更魁梧，剪影复杂度高。

### 2.5 UI 视觉基调（与 Phaser DOM 混合架构对齐）

> 战斗在 Canvas，界面用 DOM（`index.html` 手写 HUD/按钮/面板，见 `docs/02` 第一节）。本节给 DOM UI 立基调，方便后续文策渊的 UX 规格引用。

- **基线**：玻璃拟态 + 深色半透（`rgba(10,14,26,0.85)` 底 + `1px #4A5E8C` 边 + `backdrop-filter` 模糊），与夜色山水一致。
- **按钮主色**：
  - 行动按钮 = 剑青 `#4AC0D0`
  - 危险按钮 = 赤焰 `#C03A2A`
  - 稀有按钮 = 天机金 `#D4A04A`
- **字体**（待文策渊在 UX 规格中确认）：
  - 中文：等宽中文（思源黑体 / 站酷高端黑）
  - 战斗飘字：`Press Start 2P` 像素风
- **HUD 数字**：金色 `#FFB84A` 描黑边。
- **命中飘字颜色**（与品质色双编码思路一致）：
  - 物理 = 白
  - 火 = 橙
  - 冰 = 蓝
  - 毒 = 紫
  - 会心 = 红 + 加粗 + 前缀符号 `★`
- **按钮可达区域**：移动端单手拇指可达，最小点击区 **44×44 CSS px**（WCAG / Apple HIG 一致）。

### 4.4 一致性校验要点（每次交付必过）

- **网格严格对齐**：6 列 × 4 行 = 24 帧，64×64/帧（错位 1 px 也要返工；仙子表是用 `scripts/rebuild-fairy-sheet.py` 重建的正面范例）。

## 5. 可访问性基线（lean 级）

### 5.1 分级与原则

本次迭代采用 **Lean（必做最小集）** 级别。

- **核心原则**：所有**关乎玩法识别**的信息（品质、伤害类型、职业），**绝不只靠颜色通道**。
- **范围**：
  - **必做**（lean）：品质色双编码、UI 对比度、飘字差异化符号、按钮最小点击区 44×44。
  - **可选**（P2 锦上添花）：色盲模式、屏幕震动可关闭、字体大小缩放（DOM UI 天然支持，需审计）。

### 5.2 品质色双编码（必须落实）

| 品质 | 色 | 边框 | 光柱密度（粒子/秒） | 形状点缀 |
|---|---|---|---|---|
| 凡品 | 白 | 无 | 0 | — |
| 灵品 | 绿 | 单线 | 4 | — |
| 宝品 | 蓝 | 单线 + 1 角 | 8 | 1 个角标 |
| 玄品 | 紫 | 双线 | 14 | 2 个角标 |
| 仙品 | 橙 | 双线 + 旋转 | 22 | 旋转光环 |
| 传说 | 红 | 双线 + 脉动 | 32 | 旋转 + 上升粒子 |

→ 任何一项独立都可识别品质，**不依赖颜色**。

### 5.3 区域主题色与品质色冲突处理

- **赤炎魔窟**（赤红主色 `#C03A2A`）与**传说品质**（红 `#E04050`）色相接近 → 怪物身上品质词缀用**边框 + 角标**显示，避免与场景色冲突。
- **无尽妖域**（妖红主色）与传说/仙品橙可能撞色 → 同上，依赖边框 + 粒子密度区分。

### 5.4 UI 对比度与可达性

- HUD 文字与底色对比度 ≥ **4.5:1**（WCAG AA）。
- 战斗飘字伤害类型用**前缀符号**（与颜色同时呈现）：
  - 物理 = `⚔`（白）
  - 火 = `火`（橙）
  - 冰 = `❄`（蓝）
  - 毒 = `☠`（紫）
  - 会心 = `★`（红 + 加粗，前缀强制）
- 移动端按钮最小点击区 **44×44 CSS px**。
