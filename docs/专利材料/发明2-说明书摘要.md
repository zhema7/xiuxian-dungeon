# 说明书摘要

本发明公开了一种基于统一修饰聚合的攻击形态动态求值方法，涉及计算机游戏软件领域。该方法包括：定义包含固定键集合的统一修饰向量 `Mods`；将来自装备、词缀、套装、心法与天赋的多来源修饰归一化累加到该向量，得到聚合修饰；依据优先级链从聚合修饰实时求值当前攻击形态，优先级链为"套装触发效果优先于主修招式、主修招式优先于职业默认形态"。套装触发效果可同时改写普攻攻击形态与神通形态，且以套装件数达到阈值为条件。攻击形态与套装效果均以配置数据登记，新增形态不改动主战斗流程。本发明适用于移动端竖屏单手操作场景，玩家以单一攻击键即可触发由优先级链求值得出的当前攻击形态，将有限的操作维度与复杂的 Build 体系解耦，消除了多来源修饰间的耦合，实现了数据驱动的攻击形态扩展，提升了游戏可玩性与可维护性。
