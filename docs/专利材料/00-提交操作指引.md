# 发明 1 专利文件提交操作指引（CNIPA）

> 本指引针对"专利业务办理系统上传 XML 压缩包提示 XML 解析/标签校验失败"的问题，给出可落地的解决方案。

---

## 一、为什么之前的手写 XML 会校验失败

国家知识产权局自 **2026 年 1 月 1 日**起已**全面实施 XML 格式强制提交**，不再接受 PDF / DOC 等非 XML 格式（依据《关于全面实施以可扩展标记语言格式提交专利电子文件相关事宜的通知》）。

系统对 XML 有**专属数据标准 Schema（DTD 校验）**，手写 XML 几乎必然失败，原因包括：

1. **命名空间/根元素不符**：原先的 `发明1-说明书.xml` 声明的是 `WIPO ST.36` 命名空间、元素名（`patent-description`/`technical-field` 等）均为自定义，而国知局要求的是其自有数据标准规范。
2. **字符集不符**：系统要求 **GB18030**（非 UTF-8）。
3. **段号/权项号规则**：新申请文件的说明书段号、权利要求权项号由系统**自动生成**，不能手写。
4. **官方明确要求**：应使用"专利业务办理系统提供的编辑器编辑提交 XML 文件"，并提供了官方转换工具。

**结论：不要用通用/手写 XML 直接上传，必须用国知局官方「WORD转XML编辑器」从规范的 Word 文件转换。**

## 三、正确提交步骤

### 步骤 1：下载官方转换工具
- 登录 **专利业务办理系统网页版** https://cponline.cnipa.gov.cn
- 进入「**工具下载**」栏目 → 下载「**WORD转XML编辑器**」（及《专利电子申请数据标准规范》《用户操作手册》备查）

### 步骤 2：准备并核对 Word 源文件
- 用 **Microsoft Word** 打开上述三份 .docx；
- 按《审查指南》版式核对并设置（若需微调）：
  - 字体：正文**仿宋_GB2312 / 宋体**，专利权人为单位时请求书用仿宋；
  - 字号：正文**小四（12pt）**，段落标题可小四或四号；
  - 行距：固定值 **22~28 磅**或 1.5 倍；
  - 页面：纵向 **A4**，页边距上/左 2.5cm、下/右 2cm；
  - **不要手动加段号/权项号**（系统自动生成）；
  - 字符限 **GB18030 范围内**，不出现自造字。

### 步骤 3：转换生成合规 XML
- 打开「WORD转XML编辑器」→ 导入上述 .docx → 按提示转换；
- 工具会输出符合国知局数据标准的 **XML 文件**（段号/权项号由系统补填）。

### 步骤 4：处理附图
系统要求附图为 **JPG / TIF（72–300 DPI，黑白线条；TIF 必须用 Group 4 压缩；图号以文字表示、不烧进图内）**。
- 将三份 `.svg` 转成 JPG/TIF：用浏览器打开 SVG → 另存为 PNG（≤150 DPI）→ 用画图/Photoshop 转 JPG；或用 Inkscape：
  ```
  inkscape 附图1-系统模块图.svg --export-type=png -w 1240   # ≈150 DPI
  ```
  再转为 JPG/TIF。

### 步骤 5：打包上传
- 将 XML（及附图 JPG/TIF）按系统要求打包为**案卷包/压缩包**；
- 在专利业务办理系统「上传文件」环节导入，**先用编辑预览功能检查**内容是否正常、有无损坏/乱码；
- 确认无误后签名提交。

## 四、常见校验错误与规避

| 报错 | 原因 | 规避 |
|---|---|---|
| XML 解析/标签校验失败 | 手写 XML 不符合 Schema | 改用官方 WORD转XML 编辑器转换 |
| 字符不在 GB18030 范围 | 自造字/特殊符号 | 使用标准汉字，公式上下标用 `<sup>`/`<sub>` |
| 图片超限/格式不符 | DPI、格式或图号烧进图内 | JPG/TIF 72–300DPI，图号用文字标注 |
| 段号/权项号重复或缺失 | 手写了编号 | 删除手写编号，交由系统生成 |
| 加密/宏/超链接 | Word 含修订、批注、水印 | 清理文档，仅留纯文本与图片 |

## 五、重要提醒

- ⚠️ **先申请后公开**：正式提交前，勿对外公开游戏、上架或开源代码，以免丧失专利新颖性。
- 当前 .docx 为**申请阶段内部排版稿**，最终以官方编辑器转换出的 XML 为准；如代理机构介入，以其定稿版本提交。
- 附图 SVG 为矢量底稿，正式提交需按第四节要求转成 JPG/TIF 并嵌入案卷包。
