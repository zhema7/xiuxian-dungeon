## 1. 改造前的问题

| 项 | 改造前 | 影响 |
| --- | --- | --- |
| 属性 | `hpForRealm/atkForRealm/defForRealm/spdForRealm` 四条单参数公式，只吃「境界 + 等级」 | 同龄同境界的 NPC 数值几乎一样 |

## 2. 三维度模型

属性由 **修为 × 经历 × 时间** 三个维度合成，再叠加装备加值与功法百分比：

```
基础(境界/等级) → ×经历(体质·道途·出身·职业·心性·隐秘) → ×道行(年岁+突破+在世历练)
   → +装备(真实四件) → ×功法 mods(心法/神通) → 钳制 → power 战力评分
```

### 2.1 修为（主驱动）

| 项 | 公式 |
| --- | --- |
| 气血 | `(90 + 境界×140 + 等级×22) × 经历 × 道行 × 境界倍率` |
| 攻击 | `(12 + 境界×15 + 等级×3.2) × 经历 × 道行 × 境界倍率` |
| 防御 | `(9 + 境界×12 + 等级×2.2) × 经历 × 道行 × 境界倍率` |
| 身法 | `(8 + 境界×2.2 + 等级×0.15) × 经历` |
| 会心 | `0.03 + 经历会心 + 装备会心 + 功法会心`（钳制 `0~0.6`） |
| 境界倍率 | `1 + 境界×0.18`（玩家为 `+0.12`，NPC 历练更久故略高） |

### 2.2 经历（乘性微调 + 装备/功法加权）

| 维度 | 取值 | 作用 |
| --- | --- | --- |
| 体质 | 普通 / 单灵根 / 双灵根 / 天灵根 / 异灵根 | 主修行速度（1.0 → 1.8）与上限（异灵根 攻击×1.26、会心+3%、装备品阶+0.6） |
| 道途 | 剑道 / 法修 / 体修 / 丹道 / 器道 / 符道 | 战斗倾向：剑道 攻×1.16；体修 血×1.28 防×1.16；法修 会心+4%；器道 装备强化+1 |
| 出身 | 寒门 / 世家嫡子 / 宗门遗孤 / 魔修遗脉 / 商贾 / 散修传承 / 猎户 / 书香 / 武将 / 妖族混血 | 资源与传承：世家嫡子 装备品阶+1.0；宗门遗孤 功法槽+1；魔修遗脉 攻×1.2 血×0.92；寒门 修行×1.3 但装备-0.5 |
| 职业 | 散修 / 宗门弟子 / 丹师 / 器师 / 符师 / 商人 / 镖师 / 游侠 | 偏科：器师 装备强化+1；符师 会心+3%；镖师 防×1.12；游侠 身法×1.1 |
| 心性 | 刚正 / 狡诈 / 孤僻 / 热情 / 贪婪 / 淡泊 / 好战 / 谨慎 | 小幅偏科：好战 攻×1.1 防×0.94；谨慎 防×1.08 攻×0.95；淡泊 修行×1.25 |
| 隐秘 | 10 条 | 机缘与代价：身怀重宝 装备品阶+1；暗伤隐患 血×0.9；魔种附身 攻×1.14 防×0.95；前尘记忆 功法等级+1 |

### 2.3 时间（道行 + 自行修行）

- **道行年数** `= min(900, 年岁×0.55 + 突破次数×2 + 在世天数×0.03)`
- **道行加成** `= 1 + min(0.6, 道行×0.004)`（每 100 年 +40%，封顶 +60%）
- **自行修行**：每跨 1 个苍玄历日推进一次（WorldScene.update 节流，休眠 NPC 半速）
  - 历练积累 `= 天数 × (40 + 境界×12) × 修行速度`
  - 升级阈值 `= 32 × 等级^1.45`；达标则升级（单帧最多 20 级）
  - 达到下一境界门槛（1/10/20/30/45/60/80）且判定成功 → 突破，**重铸装备 + 补录功法**，写入 `eventLog`

## 3. 装备物化

`forgeNpcGear()` 用真实 `ITEM_BASES`（排除 `test_` 与 `set_test_*`）生成四件 `EquipItem`：

| 步骤 | 规则 |
| --- | --- |
| 基座档位 | 按基座强度升序，取 `round(境界/7 × (池长-1) + 装备品阶加权×0.45 + ±0.7 抖动)` |
| 缺件率 | `clamp(0.32 - 境界×0.045 - 装备品阶加权×0.06, 0.02, 0.5)`（寒门低境界常缺靴/头） |
| 品质 | `clamp(round(境界×0.5 + 品阶加权×0.7 + (25% 概率 +1)), 0, 3)` |
| 强化 | `clamp(round(境界×0.6 + 强化加权), 0, ENH_MAX)` |
| 数值倍率 | `QUALITY_MULT[品质] × (1 + 境界×0.55 + 等级×0.012)`；强化按 `+2/级` 计入（与队员面板同口径） |

- 槽位固定 `weapon / head / armor / boots`（对齐 v4 四件制，不设饰品槽）
- `uid` 前缀 `npcgear_` → `isNpcOwnedItem()`：队员换装时**不进玩家行囊**，避免生成物污染背包与掉落池

## 4. 功法装配

`buildNpcLoadout()` 按道途取技能池（剑道/体修→sword，法修/符道→mage，丹道/器道→fairy）：

| 项 | 规则 |
| --- | --- |
| 门数 | `clamp(round(1 + 境界×0.9 + 槽位加权), 1, 4)`；第 1 门固定招式，其后按 心法 → 神通 → 心法二 补齐 |
| 修炼等级 | `clamp(round(境界×0.75 + 等级加权 + 道行×0.01) + (30% 概率 +1), 1, 5)` |
| 属性影响 | 心法 `mods` 按修炼等级取 `upgrades[lv-1].mods`：atkPct / defPct / hpPct / aspd / crit / maxHp |
| 威力 | 招式 power 记录为 `stylePower`；神通 power 计入战力评分（×90） |

## 5. 战力评分与组队倍率

```
power = 血×0.35 + 攻×6 + 防×4 + 身法×2 + 会心×300 + 神通威力×90
倍率   = clamp(0.5 + 0.45 × (npcPower / 玩家战力)^0.75, 0.45, 2.2)
```

- 玩家战力优先取**真实属性**（`calcStats(state)`），无 state 时用等级曲线兜底
  （`estimatePlayerPower` 含二次项，模拟装备/心法/天赋复利；线性曲线会系统性低估中后期玩家）
- 开方压缩避免高阶 NPC 倍率爆炸：战力 3 倍于玩家 → 约 1.53 倍；同级同行 → 约 0.95~1.2

## 6. 宗门 / 城镇 NPC（派生档案）

`NPC_DEFS` 的 20 位固定 NPC（玄清子、陆青鸢、雷震、独孤剑…）不参战、不入队，
因此**不入库**，改用 `sectNpcProfile()` 按需派生（由 `id` 哈希保证稳定）：

- 角色 → 职业 / 出身 / 隐秘映射（擂台冠军 = 游侠+猎户出身+魔种附身；客栈掌柜 = 商人+寒门+暗伤隐患）
- 派生结果用于：对话详情面板（战力 / 法器 / 功法）、切磋胜负判定（此前是 `境界×12 + 等级` 的拍脑袋公式，现改为真实战力对比）

## 8. 已知边界 / 后续

- **P3 未做**：套装效果（NPC 可能拿到套装件，但只吃基座数值不吃套装加成）、队员天赋树、装备强化入口
- NPC 身法受装备影响会出现「高境界反而更慢」的局部倒挂（装备 speed 主导），不影响战斗（战斗走 `speedMult`）
- 宗门 NPC 的派生档案不随其 `updateNpcGrowth` 突破而持久化重铸（每次按需重算，天然同步）
- 待观察：大世界长期挂机后 NPC 战力膨胀速度（当前历练 `40 + 境界×12`/日，可调）
