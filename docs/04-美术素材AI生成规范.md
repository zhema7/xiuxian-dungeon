# 04 · 美术素材 AI 生成规范

本文档约定所有 AI 生成美术素材的**技术规格、命名规则、目录结构与提示词模板**。
只要按本规范产出素材并放入指定目录，游戏即可自动加载，无需改代码（角色帧表除外，需附带 JSON 配置）。

---

## 一、通用硬性要求（所有素材）

| 项目 | 要求 |
|---|---|
| 格式 | PNG（RGBA，**透明背景**；地图背景除外，可为不透明） |
| 尺寸 | 必须是 **16 的整数倍**（16/32/48/64…），游戏以最近邻缩放，保持像素锐利 |
| 风格 | 2D 像素风（pixel art），色块干净、无抗锯齿模糊边、无渐变光晕 |
| 视角 | 俯视 3/4 视角（top-down 3/4 view），与现有角色一致 |
| 描边 | 建议 1px 深色描边，保证在深色地面上可辨识 |
| 禁止 | 不要白色/纯色底、不要投影贴地死黑块、不要照片质感、不要文字水印 |

**AI 提示词通用后缀（所有素材都建议加上）：**

```
pixel art, 16-bit retro RPG style, top-down 3/4 view, clean silhouette,
1px dark outline, transparent background, no anti-aliasing, no gradient glow,
no text, no watermark, crisp pixels
```

**中文反向约束（如果生成工具支持负面提示词）：**

```
负面：白色背景，模糊边缘，抗锯齿，照片写实，3D 渲染，渐变光晕，文字，水印，阴影贴图
```

---

## 二、目录与命名规则

所有散图素材放入：`public/sprites/`，**文件名 = 游戏内贴图 key**，即 `{key}.png`。
未提供的 key 会继续使用程序化占位图，可以分批替换。

角色帧表（多帧动画）放同一目录，由 3 个文件组成一套（见第四节）。

### 3.2b 开机画面背景 `title_bg`（720×1280 竖屏，不透明）

开机画面整图背景。游戏视口 360×640，按 cover 模式等比缩放铺满，**建议 720×1280（2 倍）保证清晰度**，360×640 亦可。缺失时游戏用程序化夜景兜底，放入 `public/sprites/title_bg.png` 即自动生效。

构图要点（配合标题与按钮布局）：

- **上 1/3 留空放标题**：建议星空 / 圆月 / 云海，元素别太密
- **中部为主体**：青冥山主峰剪影、云雾缭绕，可点缀仙鹤、剑光、山间灯火
- **下 1/4 保持深色简洁**：按钮区（开始仙途 / 继续前缘 / 查看榜单），避免亮色干扰阅读
- 色调：青蓝紫夜色为主，金色灵光点缀，与 `cave_bg` 同风格
- 无需透明通道；不要出现文字、LOGO、人物正面特写

```
pixel art game title screen background, vertical 720x1280 portrait, xianxia
night scene, full moon and starry sky in upper third, majestic misty mountain
peak silhouette in the middle with glowing sword light streaks and crane birds,
warm lantern dots along a mountain path, dark clean lower quarter, deep
blue-purple night palette with golden spiritual light accents, 16-bit JRPG
style, no characters close-up, no text, no logo
```

```
像素风游戏开机背景，竖屏 720x1280，玄幻修仙夜景：上三分之一星空圆月，
中部云雾缭绕的仙山主峰剪影、剑光与仙鹤、山径灯火，下四分之一深色留白，
青蓝紫夜色调配金色灵光，16-bit JRPG 风，不要人物特写，不要文字和LOGO
```

### 3.2c 开屏视频 `title_bg.mp4`（可选增强）

开机画面支持视频背景：把 `title_bg.mp4` 放入 `public/sprites/` 即自动生效（优先级高于静态图，自动静音循环播放；播放失败自动回退静态图）。

- **格式**：MP4（H.264），必须兼容移动端 WebView；**无声轨**（游戏静音播放）
- **尺寸**：720×1280 竖屏
- **时长**：8~15 秒无缝循环
- **体积**：建议 ≤ 8 MB（码率 4~6 Mbps 足够），注意包体总上限 300 MB
- **内容**：建议用 `title_bg.png` 做图生视频（可灵 / 即梦 / Runway / Pika），只让云雾流动、星光闪烁、剑光掠过即可；上 1/3 标题区与下 1/4 按钮区运动幅度要小，避免干扰阅读

> 图生视频提示词示例：
> ```
> subtle ambient animation of this pixel art night mountain scene: clouds
> drifting slowly, stars twinkling, occasional sword-light streak across the
> sky, cranes gliding; keep camera static, seamless loop, no zoom
> ```

## 四、角色帧表规范（玩家 / 将来的人形 NPC、人形 Boss）

这是要求最高的一类素材，请严格按本节执行——目前剑修、仙子的 V2 素材就是按此规范接入的。

### 4.1 母版布局

- **单方向母版**：只需绘制**一个方向**（建议 right 或 down 为基准），其余方向由程序变换
  ⚠️ 若你能真实绘制四方向，更好——请在交付时说明"四方向均已真实绘制"，我会移除 `classes.json` 中的方向修正表（`dirRemap`）
- 网格：**6 帧 × 4 个动作**，每帧 64×64 px
- 行顺序固定（从上到下）：
  1. `idle` 待机（6 帧循环）
  2. `walk` 行走（6 帧循环）
  3. `attack` 攻击（6 帧，一次性播放）
  4. `hit` 受击 或 `cast` 施法（6 帧，一次性播放；**交付时说明第 4 行是哪种**）
- 整表尺寸：`6列 × 4行 × 64px = 384×256`（带法球/武器挥光可加宽到 7 列，需说明）

### 4.2 提示词模板（角色帧表）

```
pixel art character sprite sheet, Chinese xianxia sword cultivator,
white and azure robe, holding a jian sword, 6 animation frames per row,
4 rows: idle / walk / attack / hurt, each frame 64x64 pixels,
grid layout 6 columns x 4 rows, consistent character across all frames,
facing right, top-down 3/4 view, transparent background,
no background scenery, crisp pixels, no anti-aliasing
```

```
像素风角色精灵表，修仙剑修，白青长袍手持长剑，每行 6 帧动画，
共 4 行：待机/行走/攻击/受击，每帧 64x64 像素，6列x4行网格，
所有帧角色完全一致，面朝右侧，俯视 3/4 视角，透明背景，不要场景
```

⚠️ AI 生成后**必须人工检查**：① 各帧角色是否一致（AI 常换发型/配色）；② 网格是否严格对齐（错位就要手工切帧重排，像仙子表那样用脚本重建）。

### 4.3 配套 JSON（交付帧表时必须同时提供）

1. **Atlas（`*_atlas.json`）**：Phaser 3 `JSON Hash` 格式（TexturePacker 导出），
   每帧一个条目，**`filename` 字段必须按"动作_帧号"命名**：`idle_00`…`idle_05`、`walk_00`…、`attack_00`…、`hit_00`…
   ❌ 不要用全局连续编号（`frame_000`~`frame_095`）——之前有一版素材因此无法映射动画而废弃
2. **动画配置（`*_anims.json`）**：16 组动画定义 = 4 动作 × 4 方向，
   key 格式 `{动作}_{方向}`（如 `walk_left`），帧率约定：idle 8fps / walk 12fps / attack、hit、cast 10fps
3. 方向派生约定：down 原始帧、left = 水平翻转、right 原始、up = 垂直翻转；
   若素材实际朝向与此不符，**不用重画**——告诉我哪几个方向反了，我在 `classes.json` 的 `dirRemap` 里配置修正即可（当前：剑修四方向全换、仙子仅上下互换）

## 五、接入流程

1. 按本规范生成素材 → 人工抠图/对齐检查（透明底、网格对齐）
2. 文件改名后放入 `public/sprites/`（角色帧表为 3 件套：`*_spritesheet.png` + `*_atlas.json` + `*_anims.json`）
3. 在对话里告诉我"已放入 xxx"，我会：接入加载代码 → `npm run build` 验证 → 你直接在预览里看效果
4. 新类型素材（如新怪物、新地区地块）需要我**先注册贴图 key**，再生成对应 PNG——建议开工前先问我要 key 表
