## 一、版本概述

v0.7 是弟子养成与宗门经营系统的深化版本，在 v0.6 的基础上完成了弟子数据结构全面化、灵石灌顶系统、弟子在外遇袭事件系统、仇人名录与复仇战斗、弟子间社交互动、修炼疲劳机制、事件日志分页等功能，同时修复了 NPC 对话英文显示、雷劫触发异常、撤退按钮文字错误等遗留问题。

## 二、新增功能

### 2.1 弟子数据结构全面化

弟子新增 9 个 NPC 级别字段，与大地图 NPC 同等丰富程度：

| 字段 | 说明 | 示例 |
|------|------|------|
| `gender` | 性别 | male / female |
| `daoPath` | 道途 | 剑道/丹道/器道/符道/体修/法修 |
| `background` | 出身背景 | 寒门子弟/世家嫡子/宗门遗孤/魔修遗脉等10种 |
| `physique` | 体质 | 普通/单灵根/双灵根/天灵根/异灵根 |
| `lifeGoal` | 人生目标 | 飞升长生/报仇雪恨/守护宗门等10种 |
| `profession` | 职业身份 | 散修/丹师/器师/符师等8种 |
| `personality` | 性格特征 | 刚正/狡诈/孤僻/热情等8种 |
| `appearanceSeed` | 程序化贴图种子 | 调用 `getOrCreateNpcTexture` 生成专属像素贴图 |
| `sectX/sectY/targetX/targetY` | 宗门内坐标 | 用于游荡显示 |

### 2.2 灵石灌顶系统

- **消耗公式**：`baseCost = (0.5 + realm × 0.2) × expToNext`，境界越高每点经验消耗灵石越多
- **操作入口**：弟子详情面板 → 灵石灌顶
- **突破判定**：经验达到阈值后自动突破，触发事件记录
- **境界消耗梯度**：练气 0.5 灵石/经验 → 渡劫 2.3 灵石/经验

### 2.3 弟子在外遇袭事件系统

#### 触发机制

| 任务类型 | 基础遇袭概率 | 主要敌人 |
|----------|------------|---------|
| 采集 | 8% | 妖兽、盗匪 |
| 巡逻 | 15% | 盗匪、邪修 |
| 征讨 | 25% | 魔修、邪修 |
| 探索 | 20% | 妖兽、魔修 |

- 高境界弟子降低遇袭概率（每境界 -10%，最低 40%）
- 敌人类型按任务场景加权分布

#### 敌人种类（16种）

| 类型 | 敌人 |
|------|------|
| 盗匪 | 黑风寨盗匪、黄沙岭劫匪、血刀门残党、幽冥盗圣 |
| 魔修 | 嗜血魔修、蚀骨魔将、炼魂鬼修、血河魔尊 |
| 妖兽 | 赤眼狼群、铁甲巨蟒、玄铁背熊、三尾妖狐 |
| 邪修 | 邪修散人、逐出师门叛徒、魔道卧底、化神老怪 |

#### 四种遇袭结果

| 结果 | 触发条件 | 影响 |
|------|---------|------|
| 击退来敌 | 战力 ≥ 敌人 1.5 倍 | 任务成功 + 1.5 倍经验 + 额外缴获灵石 + 声望+5 |
| 负伤而归 | 战力 0.4~1.0 倍 | 任务失败 + 忠诚-8 + 损失物资 |
| 侥幸逃脱 | 战力 0.7~1.0 倍 | 任务失败 + 忠诚-3 + 丢失部分灵石 |
| 不幸遇害 | 战力 < 0.4 倍且 35% 概率 | 弟子阵亡 + 从宗门移除 + 声望-10 |

### 2.4 仇人名录与复仇战斗

- 所有遇袭/遇害事件自动记录到 `sect.revengeTargets`
- 宗门管理面板新增"仇人名录"按钮，可随时查看待报仇目标
- 选择报仇后进入战斗场景，敌人参数：
  - HP = 战力 × 2 + 200
  - ATK = 战力 × 0.3 + 20
- 报仇完成后目标标记为 `resolved`

### 2.5 弟子间随机互动对话

- 宗门内空闲弟子每 8-20 秒触发一次互动检查
- 触发条件：两名空闲弟子距离 ≤ 80 像素
- 对话气泡：黑色半透明圆角气泡，渐入渐出动画，持续 4 秒
- 基于 10+ 种对话场景动态生成（修炼交流/好战切磋/贪婪八卦/孤僻热情/境界差距/出身差异/魔修遗脉/日常闲聊）

### 2.6 修炼疲劳系统

| 行为 | 疲劳变化 | 经验获得 |
|------|---------|---------|
| 修炼中 | 每 60 秒 +10 | 每秒 +0.5 |
| 空闲中 | 每秒 -0.5 | — |
| 疲劳 ≥ 80 | 禁止开始修炼 | — |
| 疲劳 = 100 | 自动转为空闲，提示"修炼过度" | — |

弟子详情面板中显示 `疲劳：XX/100`。

### 2.7 事件日志分页系统

- 弟子详情面板中最近事件从 3 条扩展到 5 条
- 新增"查看全部事件"选项（仅当事件总数 > 5 时显示）
- 完整日志面板支持分页浏览，每页 10 条，可上一页/下一页
- 每条事件带类型标签（15种：招募/修炼/突破/出发/完成/失败/遇袭/遇害/获救/晋升/闭关/出关/切磋胜/切磋败/指点）

### 2.8 GM 系统扩充

- **宗门资源**：灵石+5000、灵草+100、矿石+100、木材+100、悟道+50、声望+50
- **弟子招募**：普通弟子、精英弟子（天灵根+筑基+3稀有天赋）、大师兄/姐（金丹+4紫天赋+1.5倍属性）

## 三、v0.6 遗留功能（已完成）

- 关系感知问候（7级好感梯度，从至交到仇敌）
- 玩家状态感知（低血量、境界差距、道德/声望感知）

- 寻仇概率提升至 10%-25%（随仇人数量递增）
- 偷袭（ambush）：直接进入战斗，无法回避
- 挑战（challenge）：可选择应战或回避，回避则好感-10、恐惧+5

### 3.3 拜访其他宗门

- AI 宗门互动菜单增加"拜访宗门"选项
- 拜访时可：与弟子交谈、观摩修炼、交换物资、擂台切磋、论道参悟

### 3.4 资源点擂台挑战

- 资源点交互增加"擂台挑战"选项
- 对方宗门派出弟子进行 1v1，胜方夺取资源点控制权
- 争议状态视觉指示（红色闪烁外圈 + ⚔ 标记）

### 3.5 AI 宗门智能经营

- 宗门等级提升（资源充足时 5% 概率升级，招收弟子）
- 战力随玩家进度自动调整（保持竞争力）
- 外交型宗门主动派遣使者送礼（灵石转移）
- 高好感外交型宗门主动提议通商

### 5.2 核心数据流

```
存档(localStorage) → state.ts(normalizeGameState) → 场景读取
                                                    ↓
                                              游戏内修改
                                                    ↓
                                              saveGame(state)
                                                    ↓
                                              localStorage 持久化
```

### 5.3 存档迁移链

```
v1 → v2 → v3 → ... → v11(当前, SAVE_VERSION = 11)
                   ↑
              normalizeGameState() 兜底所有新增字段
```

> **【2026-09-09 回填】** 原写「v8(当前)」已过时。实际 `SAVE_VERSION = 11`（`src/state.ts:189`），
> 且存档已从单 key 演进为**多槽位**（`MAX_SAVE_SLOTS = 4`，`xiuxian_save_slot_*` + `xiuxian_save_slots_meta`）。

### 5.4 PC 适配方案

- **分辨率**：固定 360×640 竖屏 + FIT 缩放
- **PC 模式**：隐藏触屏控件，显示快捷键提示条，鼠标瞄准攻击
- **快捷键**：WASD 移动、1-6/F1-F6 配装切换、M 地图、T 天赋、鼠标左键攻击
