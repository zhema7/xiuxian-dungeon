# 《修仙与地下城》操作说明书

> 软件名称：修仙与地下城游戏软件 ｜ 版本号：V1.0 ｜ 文档类型：用户操作手册（软著登记用）

## 第一章 软件概述

### 1.1 软件用途
《修仙与地下城》是一款竖屏像素风、玄幻修仙题材的 Web 端 Roguelike 闯关游戏。玩家扮演修仙者，进入地下城逐层挑战妖魔、获取装备功法，回洞府修炼成长，挑战更高层数。核心特色是"单一攻击键 + Build 搭配"：玩家只需一个攻击键即可战斗，角色形态由装备、功法、天赋、套装的组合动态决定。

### 1.2 运行环境
- **硬件**：PC 或移动端（手机/平板）浏览器设备
- **软件**：支持 WebGL 的现代浏览器（Chrome / Edge / Safari 等）
- **操作**：PC 端鼠标/键盘，移动端触屏（虚拟摇杆 + 攻击键）
- **分辨率**：竖屏基准 360×640，自动适配

### 1.3 启动方式
打开浏览器访问游戏地址（或本地 `index.html`），进入标题界面即可开始。

### 2.2 洞府（主城 / Town）
洞府是玩家休整与成长中枢，包含以下模块：
- **功法**：升级已习得功法（招式/心法/神通），提升威力或常驻属性。
- **炼丹**：消耗灵草炼制丹药（恢复气血、突破辅助）。
- **强化**：用灵石强化装备（+1~+5，每级提升基础数值）。
- **天赋**：分配天赋点（9 节点天赋树），获得常驻加成。
- **转职**：满足条件后转职为其他职业，重置装配并习得新默认招式。
- **配装方案**：保存/切换 5 套配装（装备+功法装配+天赋），近战/法术随时换。
- **NPC 互动**：送礼提升好感，解锁任务、组队（道友入队）、专属对话。
- **图鉴（万象图鉴）**：浏览已收集的装备/功法/套装。
- **榜单**：本地排行榜（无尽妖域最深记录、击杀等）。

### 2.3 地下城（战斗 / Dungeon）
- **移动**：虚拟摇杆或方向键控制角色移动。
- **攻击**：单一攻击键（自动朝最近敌人攻击，攻击形态由当前 Build 决定）。
- **神通**：怒气/冷却满后手动释放大招（如剑气纵横、流星火雨）。
- **拾取**：自动/手动拾取掉落（装备、灵石、丹药、灵草、无名古卷、机缘套装）。
- **楼层推进**：清怪后进入下一层；分区域：青冥山脉(1~3) → 幽冥沼泽(4~6) → 无尽妖域(7 层起·无尽)。
- **死亡惩罚**：局内死亡仅损失当次一半灵石，等级/功法/装备永久保留（软 Roguelike）。

## 第三章 核心玩法流程

### 3.1 标准循环
```
建角色 → 选难度 → 下地下城(随机迷宫逐层) → 打怪/Boss 掉装备功法
→ 回洞府(功法升级/炼丹/强化/天赋/NPC) → 挑战更高层
```

### 3.2 装备与词缀
- 装备分武器/头部/衣甲/靴子/饰品（2 个饰品位）。
- 品质：凡品/灵品/宝品/玄品（数值与词缀条数递增）。
- 词缀随机附加属性；套装（2 件/4 件）触发阶梯加成，4 件套装可改写攻击或神通形态。

### 3.3 功法四槽
- **招式**（决定普攻形态）、**心法×2**（常驻属性加成）、**神通**（手动大招）。
- 部分招式/套装限定职业，匹配职业才能生效。

### 3.4 程序化机缘内容（特色）
- **机缘套装**：无尽妖域中"天机降临"随机生成新套装并现世，永久纳入游戏配置。
- **无名古卷**：拾取后现场生成随机心法并习得。
- **名器**：稀有装备随机命名（如「庚金剑」）。

### 3.5 难度与存档
- 三档难度可选，影响强度与掉落。
- 无尽妖域每通关一个 Boss 层（每 3 层）可"存档撤离"，下次从存档点续战。
- 进度自动保存于本地（localStorage）。

## 第四章 常见问题

| 问题 | 处理 |
|---|---|
| 打不开游戏 | 确认浏览器支持 WebGL，或更新到最新版 |
| 存档丢失 | 检查是否清理了浏览器本地存储；本作为本地存档，请勿清除站点数据 |
| 卡关 | 回洞府强化装备、升级功法、调整配装方案与天赋 |
| 转职后变弱 | 转职会重置装配，需重新装备招式与心法 |
