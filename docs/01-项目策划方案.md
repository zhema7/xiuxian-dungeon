## 一、游戏概述

### 1.1 一句话定位
玩家在竖屏像素地下城中自创修仙者，选择五大职业之一，通过一层层闯关打怪获取装备、功法与资源，提升等级与境界，构建属于自己的"流派 Build"，并可与 NPC 交易、结好、组队同行，最终挑战层底大能。

### 1.2 核心体验支柱
1. **Build 自由度**：职业 × 功法 × 天赋 × 套装 = 大量可组合的战斗流派。
2. **掉落驱动**：暗黑式刷装备循环，散件追数值、套装改机制。
3. **修仙沉浸感**：境界突破、功法参悟、丹药炼制、NPC 人情往来。
4. **Roguelike 节奏**：单局 15~30 分钟，局内构筑、局外成长，死亡有惩罚但不归零。

### 1.3 平台与形态
- Web 浏览器直接游玩（PC + 移动端浏览器均可，**竖屏优先**，宽高比 9:16 设计基准）。
- 免安装、点开即玩；存档保存在本地（后续可扩展账号云存档）。

## 二、核心玩法循环

```
选择/创建角色 → 进入地下城（生成关卡层）
      ↓
探索房间 → 战斗（打怪/Boss/NPC 对手）→ 拾取装备、功法、材料
      ↓
事件房间（NPC 互动 / 宝箱 / 祭坛 / 坊市 / 灵脉）
      ↓
层底 Boss → 通关奖励（套装部件、功法残卷、天赋点）
      ↓
返回洞府（局外）：升级功法、炼丹、强化、天赋加点、NPC 好感
      ↓
挑战更高层 / 更高难度（轮回、周目）
```

- **局内死亡**：丢失本层未带回的部分战利品，保留等级、已学功法与已入背包的核心装备（降低挫败感，偏"类哈迪斯"软 Roguelike，而非硬核永久死亡）。

## 三、角色与职业系统

### 3.1 自创角色
- 捏人：像素头像/发型/服装配色（预设件组合）。
- 初始选择：职业、出身（给微小初始加成与一段专属开场事件）、姓名。

### 3.2 五大职业

| 职业 | 定位 | 武器/装备倾向 | 战斗风格 | 特色机制 |
|---|---|---|---|---|
| **剑修** | 近战输出 | 飞剑、剑丸、轻甲 | 高攻速、连击、剑气 | 「剑意」层数：连击积攒剑意，强化技能形态 |
| **仙子**（法修） | 远程法术 | 法杖/绫带、法袍 | 范围法术、控制、护盾 | 「灵韵」：施法回蓝与元素共鸣 |
| **丹修** | 辅助/召唤 | 丹炉、药杵 | 丹药 buff、毒伤、召唤药灵 | 「丹方」：战前配药，战斗中投丹触发效果 |
| **阵法师** | 控制/阵地 | 阵盘、符笔 | 布阵、陷阱、范围压制 | 「阵眼」：场上最多 N 个阵法，联动触发 |
| **魔修** | 爆发/换血 | 魔刃、骨器 | 高爆发、吸血、自残换伤 | 「魔煞」：血量越低伤害越高，斩杀回复 |

- 职业决定：可穿戴的装备类型、可学习的功法系别、初始天赋树分支。
- **不锁死**：通过稀有功法/装备可跨系混搭（如剑修魔功），支撑 Build 深度。

### 3.3 属性体系
- **基础属性**（升级获得属性点 + 自动成长）：
  - 气血（HP）、灵力（MP）、攻击、防御、速度、会心（暴击）、身法（闪避）、根骨（成长系数）。
- **境界**（独立于等级的修仙成长线）：
  - 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 大乘……
  - 突破需满足：等级门槛 + 突破材料 + 渡劫小关卡（特殊战斗/事件）。
  - 突破奖励：大量基础属性、解锁新功法槽位、解锁新地图区域。

## 四、战斗系统

### 4.1 设计原则（暗黑2 简化版）
- **只保留一种主动攻击操作**：点击/长按敌人即攻击。
- 攻击的**表现形式与效果完全由「当前主修功法 + 武器 + 套装」决定**：
  - 剑修装飞剑 → 近身三连斩；凑齐「御剑套装」→ 变为远程飞剑齐射。
  - 仙子装火系功法 → 火球；换冰系功法 → 冰锥减速。
- 其余操作：移动（虚拟摇杆/点地）、吃药、释放 1~2 个主动技能（功法附带）、队友指令（跟随/集火/待命）。
- 自动锁敌 + 攻击范围提示，保证竖屏单手可操作。

### 4.2 战斗参数
- 实时制（非回合），节奏偏快，单场小怪战 10~30 秒，Boss 战 1~3 分钟。
- 伤害公式：攻击 × 功法倍率 × 元素克制 ×（会心判定）− 防御减免，浮动 ±10%。
- 元素/流派标签：金木水火土、雷、风、毒、魔、剑——影响克制、套装与天赋联动。

### 4.3 AI 队友战斗
- NPC 队友拥有简化 AI：索敌 → 保持职业对应站位（近战顶前、远程拉开）→ 按冷却释放技能 → 低血后撤/吃丹。
- 玩家可下达三种指令：跟随、自由攻击、驻守。

## 五、关卡与 Roguelike 结构

### 5.1 地下城分层
- 每个「地区」= 一个大层（如：青冥山脉、幽冥沼泽、赤炎魔窟、天机遗迹……），包含 5~8 个小关 + 层底 Boss。
- 小关由**房间模板 + 随机种子**拼接：战斗房、精英房、宝箱房、坊市房、事件房、灵脉房（恢复）、祭坛房（献祭/祝福）。
- 通关层底 Boss 后解锁下一地区；可在洞府自由选择已解锁地区刷图。

### 5.2 敌人设计
- **魔兽**：近战冲撞型、远程吐息型、群体召唤型、护盾型等基础行为模板。
- **灵兽**：可击败也可通过特殊道具「降伏」为宠物/坐骑（二期）。
- **人形对手**：散修、魔修弟子、宗门执事——拥有与玩家类似的职业技能，掉落更好。
- **Boss**：每地区 1 个守关 Boss + 1 个隐藏 Boss（满足条件触发），机制型战斗（阶段转换、场地机制）。

### 5.3 局内成长（Roguelike 三选一）
- 每层通关 / 祭坛 / 精英掉落提供「机缘三选一」：临时功法强化、属性祝福、特殊遗物效果——当局有效，支撑局内构筑变化。

## 六、装备系统

### 6.1 装备槽位
武器、头部、衣甲、护腕、鞋子、饰品×2、法宝（职业专属槽）。

### 6.2 品质与词缀
- 品质：凡品（白）→ 灵品（绿）→ 宝品（蓝）→ 玄品（紫）→ 仙品（橙）→ 传说（红）。
- 蓝装以上带随机词缀（攻击%、会心、吸血、技能等级+1、元素伤害等），词缀池随装备部位与等级段变化。

### 6.3 套装系统（核心 Build 来源）
- 每职业 2~3 套职业套装 + 若干通用套装，2/4/6 件阶梯效果：
  - **2 件**：属性加成。
  - **4 件**：特殊能力（如剑修：剑意上限 +3，连击额外追加剑气）。
  - **6 件**：**改变攻击模式**（如普攻变为范围剑阵 / 火球变为火雨）。
- 套装主要由对应地区 Boss 与高层掉落，形成"刷特定图凑特定套"的目标感。

### 6.4 散件系统
- 无套装效果的强力单件：极端数值（如"攻击 +45%，灵力上限 −30%"）或独特机制（如"暴击时召唤剑灵"），供极限 Build 使用。

### 6.5 强化与打造
- 强化：消耗灵石 + 材料提升装备等级（有安全段与失败段）。
- 洗炼：重铸词缀；传承：将词缀/强化转移到新装备（降低换装备成本）。

## 七、功法、技能与天赋系统（参考《觅长生》）

### 7.1 功法体系
- 功法 = 可装备的"技能书"，分**心法**（被动/属性）、**招式**（改变攻击模式）、**神通**（主动技能）三类。
- 获取：怪物掉落残卷、坊市购买、NPC 传授（好感度解锁）、遗迹参悟。
- 功法养成：消耗悟道点 + 同系残卷升级（提升倍率/解锁形态），可「遗忘」返还部分资源。

### 7.2 天赋树
- 每职业一棵天赋树（3 条分支，如剑修：快剑 / 重剑 / 剑气），每级获得 1 点天赋点。
- 另有**通用天赋页**（生存、机缘、财缘——影响掉落、商店价格、事件收益），支撑非战斗流派。
- 允许付费（游戏内资源）洗点。

### 7.3 技能槽
- 主动技能槽：2 个（随境界提升到 3 个）。
- 被动功法槽：初始 2 个，随境界扩展至 5~6 个——槽位本身就是成长目标。

## 八、NPC 互动系统

### 8.1 NPC 类型
- **坊市商人**：买卖装备/丹药/功法残卷，好感度高解锁稀有货与折扣。
- **宗门NPC**：发布任务、传授功法、兑换贡献。
- **散修/奇遇NPC**：随机事件（论道、切磋、托付、骗局）。
- **可招募伙伴**：有名有姓的剧情 NPC，可邀请入队。

### 8.2 好感度系统
- 行为影响：送礼（按 NPC 喜好表）、完成任务、对话选项、切磋胜负。
- 阶段：陌生 → 相识 → 友善 → 信赖 → 生死之交。
- 解锁：折扣 / 独家功法 / 入队资格 / 专属剧情与奖励。

### 8.3 组队系统
- 最多携带 2 名 NPC 伙伴下本，伙伴有独立等级、装备页（简化）、功法配置。
- 伙伴在战斗中的贡献与好感度/境界挂钩；伙伴重伤则本局离队回洞府休养。

### 8.4 任务系统
- 主线：境界突破与地区解锁驱动的剧情线。
- 支线：NPC 委托（讨伐、收集、护送、论道）。
- 悬赏：每日/每周刷怪目标（后期留存手段）。

## 十、UI / UX（竖屏优先）

- 基准分辨率 750×1334（9:16），自适应缩放。
- 战斗画面：上半屏场景，下半屏操作区（左侧虚拟摇杆、右侧攻击/技能/丹药大按钮，单手拇指可达）。
- 核心界面：角色（属性/装备/功法/天赋）、背包（筛选/一键出售）、地图选层、坊市、洞府、NPC 对话。
- 战斗反馈：飘字（伤害/会心/掉落）、拾取光柱按品质着色（暗黑式光柱）、屏幕震动与像素打击特效。

---

## 十一、美术与音效

- **像素风**：角色 32×32 / 48×48 精灵图 + 帧动画（待机/移动/攻击/受击/死亡）；场景 16×16 tile 拼接。
- 整体色调：青绿山水底 + 各区域主题色（魔窟赤红、沼泽幽紫）。
- 特效：像素粒子（剑气、法术、爆炸）+ 着色器光晕。
- 音效：8bit/国风混合 BGM；攻击、掉落、突破等关键音效优先。
- 素材来源：先以免费/CC0 像素素材（itch.io、OpenGameArt）占位，量产期外包或自绘。

---

## 十二、数值框架（概要）

- 角色等级：1~100，经验曲线指数增长；每层怪物等级 = 层基准 ±2。
- 装备强度预算：同等级橙装 ≈ 白装 × 2.2 倍；套装 6 件效果 ≈ 一件半橙装强度（改机制不计入纯数值）。
- 掉落权重（战斗房）：白 50% / 绿 28% / 蓝 15% / 紫 5.5% / 橙 1.4% / 红 0.1%；Boss 房整体提升一档并保底蓝装。
- 详细数值表在开发期以配置表维护，单独输出《数值策划文档》。

## 十四、风险与对策

1. **内容量爆炸**（功法×职业×套装组合）→ 全部数据驱动（JSON 配置表），用编辑器/表格批量生产；先小后大。
2. **平衡难度高** → 词缀与倍率全部进配置表 + 内部模拟器跑 DPS 基准。
3. **Web 性能**（移动端）→ 对象池、图集、限制同屏特效数（详见技术方案）。
4. **单人/小团队美术产能** → 像素风 + 占位素材先行，风格统一优先于精度。
