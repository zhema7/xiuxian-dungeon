# 《修仙与地下城》游戏介绍

> 竖屏像素风 · 玄幻修仙 · Roguelike 闯关 · Web 端

---

## 一、游戏背景

青冥山，灵气钟秀之所，亦是妖气汇聚之地。

你是一名初入山门的散修，在洞府中潜心修行。山下三大秘境妖氛日盛——**青冥山脉**的走兽、**幽冥沼泽**的魑魅、以及深不见底的**无尽妖域**。守山老者说，最深处的魔将身上带着成套的仙家法宝；坊市的商人说有稀罕功法秘籍待售；山中还有一位志同道合的**道友**，正等你修为精进，结伴下山闯荡。

修行、历练、突破境界——从炼气到炼虚，你的长生之路，就藏在一层又一层的地下城里。

## 二、核心玩法

**一个攻击键打天下，build 全靠搭配。**

- **竖屏单手操作**：虚拟摇杆移动，右侧大键攻击，另有神通、丹药、背包快捷键，专为手机端设计
- **暗黑式刷宝循环**：下副本 → 杀怪掉装备 → 变强 → 挑战更深层，死亡只损失当次探索的一半灵石，等级、功法、装备永久保留
- **攻击模式随搭配而变**：没有复杂的搓招——你装什么功法、穿什么套装，攻击就是什么形态。近战扇形三连斩、穿透飞剑、360° 横扫、爆炸火弹、减速冰环……一键即成
- **程序化随机地图**：每层都是随机生成的多房间迷宫，通道、环路、石柱掩体、减速水潭，路线与走位由你自己选择
- **Roguelike 随机事件**：精英怪、宝箱、血池祭坛（献祭 25% 当前气血换本层攻击 +25%），每层都有新变数

## 三、机制详解

### 职业（当前开放 2 个）

| 职业 | 定位 | 特点 |
|---|---|---|
| **剑修** | 近战 | 血厚速快（气血 110 / 攻击 14），三段连击，可习得飞剑与横扫 |
| **仙子** | 远程法术 | 攻高身脆（气血 90 / 攻击 17），火弹爆炸溅射、冰环群体减速 |

老者处可免费**转职**，保留等级并自动习得新职业默认招式，随时体验另一种 build。

### 三大区域与关卡

| 区域 | 层数 | 守关 Boss | 环境 |
|---|---|---|---|
| 青冥山脉 | 1~3 层 | 守关魔将 | 山地岩窟 |
| 幽冥沼泽 | 4~6 层 | 泽主玄冥 | 减速水潭遍布 |
| 无尽妖域 | 第 7 层起 · 无尽 | 魔将 / 玄冥 / 深渊魔尊 每 3 层轮换 | 怪物强度随层数无限成长 |

- **无尽模式存档点**：每通关一个 Boss 层（每 3 层）可「存档撤离」，回城休整后下次从存档点继续，无需从头再打
- **难度选择**：下本前可选普通 / 困难 / 炼狱——妖魔气血、攻击、经验与高品质掉率逐档提升
- 通关前两个区域（或境界达标）可解锁后续区域

### 装备系统

- **6 个部位**：武器 / 头饰 / 护甲 / 靴子 / 双饰品
- **4 档品质**：凡品 → 灵品 → 宝品 → 玄品，数值倍率最高 2.2 倍，品质越高附带**词缀**越多（锋利、破军、嗜血、迅捷等 10 种，最多 3 条）
- **套装**（4 套）：
  - **青冥剑套**：2 件攻击 +10%；**4 件攻击化为飞剑齐射**，三柄飞剑穿透敌阵
  - **玄冥法套**：2 件技能伤害 +12%；**4 件攻击化为玄冰爆发**，大范围冰环强力迟缓敌人
  - **紫霄雷套**：2 件攻速 +8%、会心 +4%；**4 件攻击化为紫霄雷链**，命中首个目标后最多再跳传 3 次，总计最多命中 4 个目标
  - **凡人套**：2 件攻击 +15%、速度 +8；**4 件招式化为巨剑术**（巨剑气贯穿全屏）、神通化为大庚剑阵（七十二剑气全图索敌）
- **强化**：灵石强化 +1 ~ +5，每级提升 10% 基础数值
- **机缘掉落**：灵品以上装备有几率得「名器」（程序命名、数值提升）；无尽妖域 Boss 有几率现世「机缘套装」（程序生成的新套装，最多 12 套）；Boss/精英有几率掉「无名古卷」，参悟即习得随机心法
- **配装方案 ×5**：装备 + 功法 + 天赋一键整套切换，近战队、法系队随时换

### 功法与天赋

- **功法四槽**：1 招式 + 2 心法 + 1 神通。招式决定攻击形态，心法提供常驻加成（攻击、防御、会心、攻速、冷却），神通是手动释放的大招（剑气纵横：五道扇形剑气；流星火雨：七枚火弹洗地；九天神雷：五道天雷轰击四周）
- 功法用**悟道点**升级（消耗 = 当前等级 ×2，满级 5 级）
- **天赋树**：快剑 / 重剑 / 剑气三大分支共 9 节点，每升 1 级得 1 点；100 灵石可随时洗点重配

### 境界突破

炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚，共 6 重境界。每突破一重，**基础属性 +12%**。突破需要等级与突破石（打怪掉落、炼丹炉淬炼）。

### NPC 与好感度

洞府三位 NPC 各有用处，寒暄、送礼、做任务都能提升好感（陌生 → 相识 → 友好 → 信赖 → 至交），每升一档悟道 +10：

| NPC | 喜好 | 核心价值 |
|---|---|---|
| 守山老者 | 突破石 | 转职、除魔任务（悟道 +15） |
| 坊市商人 | 灵石 | 装备/功法商店，友好 9 折、信赖 8 折 |
| 道友 | 回春丹 | 好感「友好」后可**结伴入队**：道友的职业永远与你相反（你是剑修他便是仙子，你是仙子他便是剑修），剑修道友近战、仙子道友远程，攻击力为你的 80% |

**炼丹炉**：打怪掉的灵草可炼回春丹（×2）、换悟道点（×3）、淬突破石（×8）。

## 四、新手攻略

### 开局路线（1~3 层）

1. 先在洞府跟三位 NPC 各聊一次（首次寒暄好感 +3），接下老者的「除魔卫道」任务再下山
2. 一层腐液兽动作慢，贴身绕背三连斩即可；二层吐息蟾是远程，**优先走位贴脸**，别跟它对射
3. 灵石别乱花，攒着等商店刷新**武器**；早期一把灵品青锋剑顶半套装备
4. 血池祭坛看血量再点：满血献祭稳赚，残血别碰
5. 打不过 Boss 就回城——死亡只丢一半当次灵石，装备经验全保留

### Boss 应对

- **守关魔将 / 泽主玄冥**：都会蓄力冲撞（身体泛红时横向走位躲开），撞完有硬直，是最好的输出窗口
- **泥甲玄龟**防高攻低，慢慢磨；**蚀骨花**是固定炮台，绕石柱卡视野逐个击破
- 进 Boss 层前留好丹药和神通冷却

### Build 推荐

- **剑修近战流**：三连斩 + 太一剑经 + 玄武真诀，天赋点重剑系（崩山/镇岳），站撸到底
- **剑修飞剑流**：凑齐青冥剑套 4 件 + 御剑术，天赋点剑气系减神通冷却，飞剑穿透清屏
- **仙子冰控流**：冰环术 + 冰心诀，搭配玄冥法套 4 件强化减速，利用走位拉开距离
- **仙子爆发流**：火弹术 + 灵犀诀堆会心攻速，流星火雨留给精英怪和 Boss

### 资源优先级

1. **灵草**优先淬突破石（境界 +12% 是全属性提升，收益最大）
2. 送礼投其所好收益翻倍：老者喂突破石、商人喂灵石、道友喂回春丹
3. 道友尽早刷到「友好」结伴——近战配远程、远程配近战，白捡一个 80% 战力还能互补攻击模式的队友
4. 商人好感刷到信赖再买大件，八折能省一大笔
5. 无尽妖域别贪：到 Boss 层通关后**先存档撤离**，命没了什么都带不走
